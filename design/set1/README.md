# CCID4 — UI ชุดที่ 1 (หน้า 1–6)

ไฟล์ต้นฉบับของ artboard บนแคนวาสออกแบบ (รูปแบบ `.dc.html`) — ข้อมูลทั้งหมดเป็นข้อมูลจำลอง

| ไฟล์ | หน้า |
| --- | --- |
| `Main.dc.html` | 1 แดชบอร์ด (สลับ "งานของฉัน" / "ทั้งกอง (มุมมองหัวหน้า)") |
| `Cases.dc.html` | 2 รายการคดี |
| `Case.dc.html` | 3 หน้าคดี (6 แท็บ) |
| `Record.dc.html` | 4 ห้องสอบปากคำ — บันทึกเสียง (โหมดโฟกัส) |
| `Review.dc.html` | 5 ห้องสอบปากคำ — ตรวจและร่างคำให้การ |
| `Summons.dc.html` | 6 หมายเรียกชุดใหญ่ |
