# วิธีใช้ชุดพรอมต์ CCID4 กับ Claude Code

ชุดนี้ใช้สร้างระบบ CCID4 ที่ทำได้ครบเท่าระบบเดิม (MetaCops) และเพิ่มฟีเจอร์ใหม่ของ บก.สอท.4
- **โทนสี:** ฟ้า–ดำ
- **สเปก:** อยู่ใน `docs/SPEC_CCID4.md`
- **ไฟล์นี้:** บอกวิธีป้อนงานให้ Claude Code ทีละขั้น พร้อมพรอมต์ที่ก๊อปไปวางได้เลย

---

## 1. ในชุดนี้มีอะไรบ้าง

```
ccid4/
├── CLAUDE.md                        ← กติกาถาวร Claude Code อ่านเองทุกครั้ง
├── README_วิธีใช้กับ_Claude_Code.md  ← ไฟล์นี้
├── docs/
│   ├── SPEC_CCID4.md                ← สเปกหลัก (ส่วน A ฟังก์ชันเดิม + ส่วน B ฟีเจอร์ใหม่)
│   ├── SPEC_summons_system.md       ← สเปกย่อย: หมายเรียกจากทะเบียนคดีกอง
│   ├── SPEC_interview_recorder.md   ← สเปกย่อย: บันทึกเสียงสอบปากคำ
│   └── reference/
│       └── MetaCops_สรุปการใช้งาน.pdf ← อ้างอิงว่าระบบเดิมทำอะไรได้ (ไม่ใช่แบบหน้าตา)
└── sample_data/
    ├── mock_case_register.xlsx      ← ทะเบียนคดีปลอม คอลัมน์เหมือนของจริง
    ├── mock_complainants.xlsx       ← ข้อมูลผู้แจ้งปลอม
    └── summons_template_sanitized.docx ← แบบฟอร์มหมายเรียกที่ลบข้อมูลจริงแล้ว
```

> ห้ามใส่ไฟล์ข้อมูลจริงของกองลงในโฟลเดอร์นี้ ใช้ข้อมูลใน `sample_data/` ตอนพัฒนาเท่านั้น

## 2. เตรียมเครื่องก่อนเริ่ม

1. **ติดตั้งโปรแกรม:** Git, Docker Desktop และ Claude Code (ตามคู่มือของ Anthropic)
2. **แตก ZIP:** แตกไฟล์ชุดนี้ไว้ในโฟลเดอร์ เช่น `C:\dev\ccid4` หรือ `~/dev/ccid4`
3. **สร้าง Git repo:** เปิด Terminal ในโฟลเดอร์นั้นแล้วรัน
   ```bash
   git init
   git add .
   git commit -m "เริ่มโปรเจกต์ CCID4: สเปกและข้อมูลตัวอย่าง"
   ```
4. **ฟอนต์:** หาไฟล์ฟอนต์ TH SarabunIT๙ (ฟอนต์ราชการ) มาใส่โฟลเดอร์ `fonts/`
5. **เปิด Claude Code:** พิมพ์ `claude` ใน Terminal ที่อยู่ในโฟลเดอร์โปรเจกต์

> ถ้าเครื่องไม่มีการ์ดจอ ไม่เป็นไร ช่วงพัฒนาใช้ `FakeLLM` แทน AI จริงได้ (เขียนไว้ในสเปกแล้ว) ค่อยต่อ AI จริงตอนติดตั้งบนเครื่องเซิร์ฟเวอร์ของหน่วยงาน

---

## 3. หลักการป้อนงานให้ Claude Code (อ่านก่อน)

1. **ทำทีละเฟส:** อย่าสั่งให้ทำทั้งระบบในพรอมต์เดียว งานใหญ่ขนาดนี้ถ้าสั่งทีเดียวจะได้ของครึ่ง ๆ กลาง ๆ
2. **ให้เสนอแผนก่อนเสมอ:** กด `Shift+Tab` เพื่อเข้า Plan mode หรือใช้พรอมต์ที่เขียนว่า "เสนอแผนก่อน ยังไม่ต้องเขียนโค้ด"
   - อ่านแผนให้ดี ถ้าไม่ตรงให้แก้ตั้งแต่ตอนนี้
3. **จบเฟสต้องทดสอบเอง:** เปิดเว็บ ลองกดตามที่ Claude สรุปให้ ถ้าโอเคค่อย commit
   ```bash
   git add . && git commit -m "เฟส 2: หน้าคดีและระบบบันทึก"
   ```
4. **ขึ้นเฟสใหม่ให้ล้างบริบท:** พิมพ์ `/clear` แล้วเริ่มด้วยพรอมต์ของเฟสถัดไป
   - Claude จะอ่าน `CLAUDE.md` และ `docs/PROGRESS.md` เองว่าทำอะไรไปแล้ว
5. **เจอ error ให้วางข้อความ error ทั้งหมด:** อย่าเล่าเอง วางแบบเต็ม พร้อมบอกว่ากดอะไรถึงเกิด
6. **อยากได้หน้าตาแบบไหน ให้ส่งภาพ:** ลากภาพหน้าจอหรือภาพร่างมาวางในช่องพิมพ์ได้
   - แต่ห้ามส่งภาพหน้าจอระบบเดิมแล้วสั่งให้ทำตามเป๊ะ ให้บอกเป็นฟังก์ชันแทน
7. **ย้ำกติกาสำคัญในพรอมต์:** ถ้าเห็น Claude เริ่มใช้ CDN, API ภายนอก หรือใส่สีตรง ๆ ให้พิมพ์ว่า "ตรวจกับ CLAUDE.md อีกครั้ง"

## 4. พรอมต์ทีละเฟส (ก๊อปไปวาง)

### เฟส 0 — โครงโปรเจกต์ ธีม และระบบผู้ใช้
```
อ่าน CLAUDE.md และ docs/SPEC_CCID4.md ทั้งหมดก่อน
จากนั้นเริ่ม "เฟส 0" ตามหัวข้อ 7 ของสเปก

ขอบเขตเฟสนี้:
- โครง Django 5 + docker compose (web, worker, db, redis) และ Makefile คำสั่ง make up / make test / make seed
- design tokens ฟ้า–ดำ ตามหัวข้อ 2.1 ทั้งธีมมืดและสว่าง ผูกกับ Tailwind (self-host ทุกไฟล์ ไม่ใช้ CDN)
- base layout ตามหัวข้อ 2.3: แถบบน แถบเมนูซ้ายพับได้ ปุ่มสลับธีม (จำค่าต่อผู้ใช้)
- ออกแบบโลโก้ CCID4 เป็น SVG ของเราเอง ตามที่สเปกบอก
- ล็อกอิน + บทบาท 6 แบบ (หัวข้อ 1) + TOTP 2FA + ล็อกบัญชีเมื่อใส่ผิด 5 ครั้ง
- AuditLog middleware
- คำสั่ง seed สร้างผู้ใช้ตัวอย่างทุกบทบาทด้วย Faker th_TH
- ทำหน้า /styleguide แสดงสี ปุ่ม การ์ด ตาราง ป้าย AI ทั้งสองธีม ไว้ให้ผมตรวจหน้าตา

เสนอแผนก่อน ยังไม่ต้องเขียนโค้ด แผนต้องมี: รายการไฟล์, Django apps, คำสั่งที่จะใช้, เทสต์ที่จะเขียน
```

### เฟส 5 — AI layer
```
อ่าน docs/PROGRESS.md แล้วเริ่มเฟส 5 ตามหัวข้อ 4 และ A4.2–A4.5, A4.7

  1. วิเคราะห์ฐานความผิด/ศาล/อัตราโทษ + ปุ่มวิเคราะห์ใหม่

- ค้นฎีกา: คำสั่ง import_dika (CSV/JSON), embedding ลง pgvector, ค้นแบบ hybrid, ปักหมุดเข้าคดี
  ทำไฟล์ตัวอย่างฎีกาปลอม 20 รายการไว้ทดสอบ

เสนอแผนก่อน
```

## 6. ข้อควรระวัง

- **กำหนดเวลาตามกฎหมาย (A5):** ค่าใน A5 เป็นค่าตั้งต้น ต้องให้ฝ่ายกฎหมายหรือพนักงานสอบสวนรุ่นพี่ตรวจก่อนใช้จริง
- **ข้อมูลฎีกา:** ต้องมาจากแหล่งที่หน่วยงานมีสิทธิ์ใช้ อย่าให้ Claude เขียนโปรแกรมดึงจากเว็บไซต์โดยไม่ได้รับอนุญาต
- **ระบบเดิม:** CCID4 ทำฟังก์ชันได้ครบเท่าระบบเดิม แต่หน้าตา ข้อความ และโลโก้ต้องเป็นของเราเอง ถ้าจะนำไปใช้ในหน่วยงานจริง ควรแจ้งผู้บังคับบัญชาเรื่องความสัมพันธ์กับระบบเดิมด้วย
- **ฟีเจอร์ที่ส่งข้อมูลออกภายนอก:** ทุกอย่างที่ส่งข้อมูลออกนอกเครือข่าย (เช่น แจ้งเตือนผ่านแอปแชท) ต้องได้รับอนุมัติก่อนเปิดใช้
