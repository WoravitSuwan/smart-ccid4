# CCID4 — ระบบงานสอบสวน กก.1 บก.สอท.4 (ระยะที่ 1)

เว็บแอปที่ติดตั้งบนเซิร์ฟเวอร์ของหน่วยงาน ข้อมูลคดี เสียงสอบปากคำ และเอกสารเก็บอยู่ในเครื่องของหน่วย ไม่ส่งออกไปภายนอก

## ระยะที่ 1 ทำอะไรได้

| งาน | สิ่งที่ใช้งานได้ |
| --- | --- |
| เข้าสู่ระบบ | บัญชีตามบทบาท (พนักงานสอบสวน, ธุรการ, หัวหน้า, ผู้ดูแลระบบ) · ล็อกชั่วคราวเมื่อใส่รหัสผิด 5 ครั้ง · หมดเวลาเข้าสู่ระบบตามที่ตั้งไว้ |
| คดี | สร้างและแก้คดี · เพิ่มผู้กล่าวหา ผู้ต้องหา พยาน · ขั้นของคดี · กรอบเวลาพร้อมนับถอยหลังและการยืนยันวันครบอำนาจ |
| สิทธิ์เข้าถึง | พนักงานสอบสวนเห็นเฉพาะคดีของตน · หัวหน้าเห็นทั้งกอง · ธุรการฟังเสียงไม่ได้ · ผู้ดูแลระบบเปิดเนื้อหาคดีไม่ได้ |
| **ห้องสอบปากคำ** | เช็กลิสต์และสคริปต์แจ้งสิทธิก่อนเริ่ม → อัดเสียงจากเบราว์เซอร์ ส่งขึ้นเซิร์ฟเวอร์ทุก 5 วินาที (เน็ตหลุดก็ส่งซ้ำให้) → ปิดไฟล์และคำนวณ SHA-256 ต้นฉบับเป็นแบบอ่านอย่างเดียว · อัปโหลดไฟล์จากเครื่องบันทึกอื่นได้ |
| **ตรวจและร่างคำให้การ** | ถอดเสียงบนเครื่องของหน่วย (เมื่อติดตั้งโมเดล) หรือวางข้อความถอดเสียง/SRT/VTT/JSON · กำหนดบทบาทผู้พูด · จัดคู่ถาม-ตอบจากคำพูดจริง เปลี่ยนเฉพาะสรรพนามเป็น "ข้าฯ" · ทุกคู่มีช่วงเวลาในเสียง กดฟังได้ · **ธงเตือนตัวเลขที่ไม่พบในเสียง** (อ่านตัวเลขที่พูดเป็นคำไทยได้ เช่น "สามพัน") · **ตรวจการแจ้งสิทธิ ม.134/4 จากเสียง** · ยืนยันได้เมื่อตรวจครบทุกคู่และแจ้งสิทธิครบ (หรือยืนยันด้วยตนเอง) · ส่งออก Word/PDF พร้อม SHA-256 ของเสียง |
| **หมายเรียกชุดใหญ่** | นำเข้าทะเบียน Excel/CSV (หาหัวคอลัมน์ให้เอง) → คัดคดีที่สิ้นสุดออก → แถวที่ที่อยู่ไม่ครบเลือกไม่ได้ → ออกหมายหลายร้อยฉบับในไฟล์เดียว เลขไทย พ.ศ. ไล่เวลานัดทีละ 30 นาทีต่อพนักงานสอบสวน พร้อมใบจ่าหน้าซอง DL · Word และ PDF |
| ประวัติการใช้งาน | บันทึกทุกการเข้าสู่ระบบ เปิดดู แก้ไข ดาวน์โหลด ฟังเสียง และยืนยัน · แต่ละรายการผูกแฮชกับรายการก่อนหน้า แก้หรือลบย้อนหลังจะถูกตรวจพบ |

หน้าอื่นในแบบออกแบบ (`design/`) เช่น รับแจ้งจากประชาชน, นำเข้า Smart Police, กราฟเส้นทางเงิน, ค้นมาตรา/ฎีกา และเอกสารสำนวนอีกกว่า 20 ชนิด อยู่ในระยะถัดไป

## ติดตั้งบนเซิร์ฟเวอร์ของหน่วย (Docker)

ต้องมี Docker และ Docker Compose บนเครื่อง Linux ในเครือข่ายของหน่วย

```bash
cd ccid4
```

```bash
cp .env.example .env
```

แก้ `.env`: ตั้ง `CCID4_SECRET_KEY` เป็นค่าสุ่มยาว ๆ (สร้างด้วย `openssl rand -hex 32`) และตั้งชื่อหน่วย

```bash
docker compose up -d --build
```

สร้างผู้ดูแลระบบคนแรก (ระบบจะถามรหัสผ่าน)

```bash
docker compose exec app python -m app.cli create-admin --email admin@police.go.th --name "ผู้ดูแลระบบ"
```

จากนั้นเปิด `https://ccid4.local` (ตั้ง DNS ภายในหรือไฟล์ hosts ให้ชี้มาที่เซิร์ฟเวอร์) เข้าสู่ระบบด้วยบัญชีผู้ดูแล แล้วเพิ่มผู้ใช้ในเมนู "ผู้ใช้และสิทธิ์"

- **HTTPS จำเป็น** เพราะเบราว์เซอร์อนุญาตให้ใช้ไมโครโฟนเฉพาะบนเว็บที่เป็น HTTPS · `deploy/Caddyfile` ใช้ใบรับรองภายในของ Caddy ให้ติดตั้ง root certificate ของ Caddy บนเครื่องของหน่วย หรือเปลี่ยนเป็นใบรับรองของหน่วย
- ไฟล์ทั้งหมด (ฐานข้อมูล เสียงต้นฉบับ เอกสาร) อยู่ใน volume `ccid4-data`

### สำรองข้อมูล

```bash
docker run --rm -v ccid4_ccid4-data:/data -v "$PWD":/backup busybox tar czf /backup/ccid4-$(date +%F).tgz -C /data .
```

เก็บไฟล์สำรองไว้ในที่ปลอดภัยของหน่วย และทดลองกู้คืนอย่างน้อยเดือนละครั้ง

### ถอดเสียงบนเครื่องของหน่วย (ไม่บังคับ)

```bash
docker compose build --build-arg WITH_ASR=true
```

ตั้ง `CCID4_ASR_MODEL` ใน `.env` (เช่น `large-v3` หรือ path ของโมเดล Whisper ภาษาไทยแบบ CTranslate2 ที่ดาวน์โหลดไว้ในเครื่อง) และ `CCID4_ASR_DEVICE=cuda` ถ้ามี GPU · เสียงยาว 1 ชั่วโมงบน CPU อาจใช้เวลาหลายชั่วโมง แนะนำเซิร์ฟเวอร์ที่มี GPU · ระบบยังไม่แยกผู้พูดอัตโนมัติ พนักงานสอบสวนกำหนดบทบาทผู้พูดในหน้าตรวจ

### ใช้ PostgreSQL แทน SQLite

ตั้ง `DATABASE_URL=postgresql+psycopg://ผู้ใช้:รหัส@โฮสต์:5432/ccid4` ใน `.env` (แนะนำเมื่อมีผู้ใช้พร้อมกันหลายคน)

## ดูหน้าตาบน Vercel (ตัวอย่างเท่านั้น)

ใช้เพื่อดูหน้าตาและลองกดใช้งานด้วยข้อมูลจำลองเท่านั้น **ห้ามใส่ข้อมูลจริง** เพราะ Vercel เป็นบริการภายนอกหน่วยงาน

1. ใน Vercel กด Add New → Project แล้วเลือก repo นี้
2. ตั้ง **Root Directory = `ccid4`** (Framework Preset: Other)
3. Environment Variables: ตั้ง `CCID4_SECRET_KEY` เป็นค่าสุ่มยาว ๆ (ถ้าไม่ตั้ง ระบบใช้คีย์ที่คาดเดาได้) และ `TZ=Asia/Bangkok`
4. Deploy แล้วเข้าสู่ระบบด้วยบัญชีทดลองที่แสดงบนหน้าเข้าสู่ระบบ

ข้อจำกัดบน Vercel: ข้อมูลเก็บใน `/tmp` และหายเมื่อเซิร์ฟเวอร์เริ่มใหม่ (ระบบใส่ข้อมูลจำลองให้ใหม่ทุกครั้ง) · ไม่มี LibreOffice จึงไม่มี PDF (ได้ Word) · ไม่มีการถอดเสียง · การอัดเสียงยาว ๆ อาจไม่สมบูรณ์เมื่อ Vercel แบ่งคำขอไปหลายเครื่อง

## พัฒนาและทดสอบ

```bash
python -m venv .venv && . .venv/bin/activate && pip install -r requirements-dev.txt

python -m app.cli demo && uvicorn app.main:app --reload
```

## ก่อนใช้กับคดีจริง (ต้องทำ)

ระยะที่ 1 พร้อมให้ทดลองใช้ในหน่วย แต่ก่อนใช้กับข้อมูลคดีจริงต้องผ่านขั้นตอนเหล่านี้

1. ผู้รับผิดชอบด้านกฎหมายของหน่วยตรวจรูปแบบบันทึกคำให้การ หมายเรียก และสคริปต์แจ้งสิทธิ ให้ตรงกับแบบฟอร์มที่หน่วยใช้
2. ทดสอบความปลอดภัย (penetration test) และตั้งค่าไฟร์วอลล์ให้เข้าถึงได้เฉพาะเครือข่ายของหน่วย
3. ประเมินผลกระทบด้านข้อมูลส่วนบุคคล (DPIA) และกำหนดระยะเวลาเก็บเสียงและเอกสาร
4. ทดลองใช้คู่ขนานกับวิธีเดิมอย่างน้อย 1 เดือน และวัดความแม่นยำของการถอดเสียงภาษาไทยกับเสียงจริงในห้องสอบสวน
5. ตั้งระบบสำรองข้อมูลอัตโนมัติ และกำหนดผู้ดูแลระบบอย่างน้อย 2 คน
