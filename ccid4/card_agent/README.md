# card-agent — อ่านบัตรประชาชนให้ CCID4

โปรแกรมเล็กที่ติดตั้งบน **เครื่องของผู้ใช้** (เครื่องที่เสียบเครื่องอ่านบัตร) ไม่ใช่บนเซิร์ฟเวอร์
หน้าเว็บ CCID4 ขอข้อมูลบัตรผ่าน WebSocket ที่ `ws://127.0.0.1:8765` แล้วแสดงหน้าตรวจทานก่อนเติมฟอร์ม

**ความปลอดภัย**
- รับการเชื่อมต่อจากเครื่องนี้เท่านั้น (127.0.0.1)
- ตอบเฉพาะหน้าเว็บ CCID4 ที่กำหนดด้วย `--origin`
- อ่านบัตรเฉพาะตอนที่กดปุ่มในหน้าเว็บ
- ไม่บันทึกข้อมูลบัตรลงดิสก์ และไม่เขียนข้อมูลบุคคลลงไฟล์ log
- การนำข้อมูลไปใช้ในคดีถูกบันทึกในประวัติการใช้งานของ CCID4

## ติดตั้ง (Windows)

1. ติดตั้งไดรเวอร์เครื่องอ่านบัตร
   - เครื่องอ่านแบบ PC/SC ทั่วไปใช้ไดรเวอร์ที่ Windows มีให้
   - ตรวจว่า Windows เห็นเครื่องอ่าน ใน Device Manager → Smart card readers
2. ติดตั้ง Python 3.12 จาก python.org (ติ๊ก *Add python.exe to PATH*)
3. คัดลอกโฟลเดอร์ `card_agent` ไปไว้ที่เครื่อง เช่น `C:\ccid4\card_agent`
4. เปิด PowerShell ที่ `C:\ccid4` แล้วติดตั้งไลบรารี (ครั้งเดียว):

   ```bash
   py -m pip install -r card_agent\requirements.txt
   ```
5. เปิดโปรแกรม (เปลี่ยน `https://ccid4.local` เป็นที่อยู่ CCID4 ของหน่วย):

   ```bash
   py -m card_agent --origin https://ccid4.local
   ```

   ถ้าใช้แบบเครื่องเดียว (`http://localhost:8000`) ไม่ต้องใส่ `--origin`

ให้โปรแกรมเปิดเองทุกครั้งที่เข้า Windows:
1. สร้างไฟล์ `card-agent.cmd` มีบรรทัด `cd /d C:\ccid4 && py -m card_agent --origin https://ccid4.local`
2. วางไฟล์นั้นในโฟลเดอร์ Startup (กด Win+R พิมพ์ `shell:startup`)

## ติดตั้ง (macOS / Linux)

```bash
python3 -m pip install -r card_agent/requirements.txt
```

```bash
python3 -m card_agent --origin https://ccid4.local
```

บน Linux ต้องติดตั้งบริการ PC/SC ก่อน (`pcscd`, `libpcsclite-dev`)

## ใช้งาน

1. หน้าคดี → แท็บบุคคล → **อ่านบัตรประชาชน**
2. เสียบบัตร หน้าตรวจทานแสดงข้อมูลและรูปจากบัตร พร้อมเตือนถ้าเลขบัตรไม่ผ่านการตรวจหลักสุดท้าย หรือบัตรหมดอายุ
3. เลือกช่องที่จะใช้ → **ใช้ข้อมูลที่เลือก** → ตรวจอีกครั้ง → กด **บันทึก** ของหน้าคดี

ไม่มีเครื่องอ่านบัตร ให้กด **อ่านจากภาพบัตร** แทน (OCR ในเครื่องของหน่วย ต้องเปิด `OCR_BACKEND=ollama`) ข้อมูลจาก OCR ต้องตรวจทุกตัวอักษรเสมอ

## แก้ปัญหา

| อาการ | วิธีแก้ |
|---|---|
| "ไม่พบโปรแกรม card-agent บนเครื่องนี้" | ยังไม่ได้เปิดโปรแกรม หรือไฟร์วอลล์บล็อกพอร์ต 8765 บนเครื่องตัวเอง |
| หน้าเว็บเชื่อมต่อแล้วถูกตัดทันที | ที่อยู่ CCID4 ไม่ตรงกับ `--origin` (ต้องตรงทั้ง http/https และชื่อเครื่อง) |
| "ไม่พบเครื่องอ่านบัตร" | เสียบเครื่องอ่านใหม่ ตรวจไดรเวอร์ |
| "ยังไม่ได้เสียบบัตร" | เสียบบัตรให้สุด ด้านชิปขึ้นตามรูปบนเครื่องอ่าน |
