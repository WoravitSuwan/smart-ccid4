# ติดตั้ง CCID4 บนเครื่องของพนักงานสอบสวน เพื่อทดลองอัดเสียงผู้แจ้งความจริง

ระบบทั้งหมดทำงานอยู่ในเครื่องนี้เครื่องเดียว ได้แก่ ฐานข้อมูล ไฟล์เสียง และโมเดลถอดเสียง
ไม่ส่งเสียงหรือข้อมูลคดีออกนอกเครื่อง ต่ออินเทอร์เน็ตแค่ตอนติดตั้งครั้งแรก เพื่อโหลดโปรแกรมและโมเดล

> **ห้ามใช้ข้อมูลจริงบน Vercel (ระบบสาธิต)** — ข้อมูลผู้แจ้งจริงต้องอยู่ในเครื่องที่ติดตั้งตามคู่มือนี้เท่านั้น

## สิ่งที่ต้องมี

| | ขั้นต่ำ | แนะนำ |
|---|---|---|
| เครื่อง | Windows 10/11, macOS 12+ หรือ Linux | โน้ตบุ๊ก/พีซี CPU 8 คอร์ขึ้นไป |
| หน่วยความจำ | 8 GB | 16 GB |
| พื้นที่ว่าง | 15 GB | 30 GB (เสียง 1 ชั่วโมง ≈ 30 MB) |
| โปรแกรม | Docker Desktop และ Chrome หรือ Edge | ไมค์ตั้งโต๊ะ/ไมค์หนีบปก แทนไมค์ในตัวโน้ตบุ๊ก |

## ติดตั้ง (ครั้งแรกประมาณ 30–40 นาที ส่วนใหญ่เป็นเวลารอดาวน์โหลด)

1. ติดตั้ง **Docker Desktop** จาก docker.com แล้วเปิดโปรแกรม รอจนมุมล่างขึ้นว่า *Engine running*
   - บน Windows ถ้าโปรแกรมขอให้เปิด WSL 2 ให้ตอบตกลงแล้วรีสตาร์ตเครื่อง
2. ดาวน์โหลดโค้ด เลือกวิธีใดวิธีหนึ่ง
   - หน้า GitHub ของโปรเจกต์ → เลือก branch `claude/clever-dijkstra-pj0j2d` → ปุ่ม **Code → Download ZIP** → แตกไฟล์
   - หรือใช้ git:

     ```bash
     git clone -b claude/clever-dijkstra-pj0j2d https://github.com/WoravitSuwan/smart-ccid4.git
     ```
3. เปิดโฟลเดอร์ `ccid4` ที่อยู่ข้างในโค้ดที่ดาวน์โหลดมา แล้วรันตัวติดตั้ง
   - **Windows:** คลิกขวาที่โฟลเดอร์ `ccid4` → *Open in Terminal* แล้วพิมพ์

     ```bash
     powershell -ExecutionPolicy Bypass -File scripts\install_local.ps1
     ```
   - **macOS / Linux:**

     ```bash
     bash scripts/install_local.sh
     ```
4. ตัวติดตั้งทำงานตามลำดับนี้
   1. สร้างไฟล์ `.env` ใส่รหัสผ่านสุ่ม ไฟล์นี้อยู่ในเครื่องนี้เท่านั้น ห้ามส่งต่อ
   2. สร้างโปรแกรม
   3. โหลดโมเดลถอดเสียง
   4. เปิดระบบ
   5. ถามข้อมูลเพื่อสร้างบัญชีพนักงานสอบสวนคนแรก: ชื่อผู้ใช้ ยศ ชื่อ นามสกุล ตำแหน่ง รหัสผ่านอย่างน้อย 12 ตัว
5. เปิด **http://localhost:8000** ด้วย Chrome หรือ Edge บนเครื่องนี้ แล้วเข้าสู่ระบบ

รันตัวติดตั้งซ้ำได้ ข้อมูลเดิมไม่หาย เช่น หลังดาวน์โหลดโค้ดเวอร์ชันใหม่

### เลือกโมเดลถอดเสียง

| คำสั่ง | ความเร็วบน CPU | ความแม่น | เหมาะกับ |
|---|---|---|---|
| ค่าเริ่มต้น `large-v3-turbo` | เร็ว: เสียง 1 ชม. ≈ 15–30 นาที | ดี | ทดลองใช้วันนี้ เครื่องทั่วไป |
| `install_local.ps1 large-v3` / `install_local.sh large-v3` | ช้ากว่า 3–4 เท่า | ดีกว่า | เครื่องแรง หรือรอได้ |
| Typhoon Whisper (ภาษาไทยโดยเฉพาะ) | ต้องมี GPU จึงจะเร็ว | ดีที่สุดสำหรับภาษาไทย | เครื่อง GPU ของหน่วย (ดูท้ายคู่มือ) |

ทั้งหมดเป็นโมเดลแบบ open-weight ที่ทำงานในเครื่องนี้ ไม่ได้เรียก API ภายนอก
เวลาประมวลผลขึ้นกับจำนวนคอร์ของ CPU หน้า "ประมวลผล" จะบอกความคืบหน้า เช่น "ถอดเสียงแล้ว 12:30 จาก 58:10 (21%)"

## วิธีใช้กับผู้แจ้งความ

1. เมนู **ห้องสอบปากคำ** → กล่อง **อัดเสียงผู้แจ้งความรายใหม่**
   - กรอกชื่อผู้แจ้ง เบอร์โทร และเรื่องที่แจ้งโดยย่อ แล้วกด **สร้างและเริ่มอัดเสียง**
   - ระบบสร้างคดีสถานะ "รับแจ้งใหม่" กับผู้กล่าวหาให้เอง
2. **แจ้งผู้ให้ถ้อยคำก่อนเสมอ** ว่ากำลังบันทึกเสียงเพื่อใช้ทำคำให้การ
   - พูดประโยคนี้ในเสียงด้วย ระบบจะตรวจพบและบันทึกไว้
3. กด **ทดสอบไมค์ 5 วินาที** แล้วฟังเสียงที่ได้ จากนั้นกด **เริ่มบันทึก**
   - ระหว่างอัดใช้ **พัก**, **หยุด** และ **ทำเครื่องหมาย** ได้ เช่น ทำเครื่องหมายตอน "เริ่มเล่าเรื่องการโอนเงิน"
4. อัดนานเป็นชั่วโมงได้
   - เสียงส่งเข้าระบบทุก 5 วินาที ถ้าเผลอปิดแท็บ ส่วนที่ส่งแล้วไม่หาย เปิดหน้าเดิมแล้วกด "บันทึกต่อ"
   - เสียบสายชาร์จ และตั้งเครื่องไม่ให้พักหน้าจอ: Windows → Settings → System → Power, macOS → System Settings → Lock Screen
   - ห้ามปิดฝาโน้ตบุ๊กระหว่างอัด
5. เล่าจบแล้วกด **ปิดการบันทึกและประมวลผล**
   - ไฟล์เสียงถูกล็อกและคำนวณ SHA-256
   - ระบบเริ่มถอดเสียงเบื้องหลัง ระหว่างรอทำงานอื่นได้ หรือรับผู้แจ้งรายถัดไปได้เลย
6. ถอดเสียงเสร็จ ระบบเปิดหน้าตรวจ ด้านบนมีกล่อง **สรุปจากเสียง** 3 แท็บ
   - **สรุปใจความสำคัญ:** เหตุการณ์โดยย่อ วันเวลา จำนวนเงิน เลขบัญชี ธนาคาร เบอร์โทร ช่องทาง และความประสงค์
   - **เล่าเรื่อง:** คำให้การแบบบรรยาย ขึ้นต้นด้วย "ข้าฯ ขอให้การว่า …" แก้ได้ทุกคำ
     - ถ้ามีตัวเลขหรือประโยคที่หาในเสียงไม่พบ ระบบติดป้ายเตือนสีส้ม
     - ฟังเสียงแล้วติ๊ก **ฟังแล้ว ตรงกับเสียง** แล้วกดบันทึก
   - **คำที่พบบ่อย:** กดคำใดคำหนึ่ง ระบบไฮไลต์ทุกช่วงที่พูดคำนั้นในข้อความถอดเสียง
7. ระบบเดาผู้พูดจากประโยค (คำถามและการแจ้งสิทธิเป็นของพนักงานสอบสวน) ถ้าเดาผิด เปลี่ยนผู้พูดในช่วงนั้นแล้วกด **ร่างใหม่**
8. กด **ยืนยันและสร้าง Word/PDF** แล้วจะได้เอกสาร 3 ชุด
   - **คำให้การ** Word และ PDF รูปแบบบรรยาย ถ้าต้องการถาม–ตอบ ให้เลือกด้านบนหน้าตรวจก่อนยืนยัน
   - **สรุปการสอบปากคำ** Word มีสรุปใจความ เรื่องราว และตารางคำที่พบบ่อย ดาวน์โหลดได้ตั้งแต่ก่อนยืนยัน
     - ก่อนยืนยันจะมีป้าย "ร่างโดย AI – รอตรวจ"
   - **ชุดหลักฐาน ZIP:** ไฟล์เสียงต้นฉบับ ข้อความถอดเสียง และ manifest พร้อม SHA-256

> คำให้การที่ได้คือร่างจากคำพูดจริง ไม่มีการแต่งเติม แต่พนักงานสอบสวน**ต้องฟังเสียงตรวจทุกครั้ง**ก่อนยืนยันและก่อนให้ผู้ให้การลงชื่อ
> อายุและที่อยู่ที่ยังไม่ได้กรอกจะพิมพ์เป็นเส้นจุดให้เขียนด้วยมือ หรือเติมในหน้าคดีก่อนกดยืนยัน

## ข้อมูลส่วนบุคคล (PDPA) ระหว่างทดลอง

- ใช้เครื่องที่เข้ารหัสดิสก์ไว้แล้ว (Windows: BitLocker, macOS: FileVault) และล็อกหน้าจอทุกครั้งที่ลุกจากเครื่อง
- ระบบเปิดให้เข้าได้จากเครื่องนี้เท่านั้น (localhost) เครื่องอื่นในวงแลนเข้าไม่ได้
- ทุกการเปิดดู ฟังเสียง ดาวน์โหลด และแก้ไข ถูกบันทึกในประวัติการใช้งาน
- จบการทดลองแล้ว ถ้าต้องการลบข้อมูลทั้งหมดรวมทั้งไฟล์เสียง ให้รันคำสั่งนี้ (ลบแล้วกู้คืนไม่ได้)

  ```bash
  docker compose -f docker-compose.local.yml down -v
  ```

## คำสั่งที่ใช้บ่อย (รันในโฟลเดอร์ `ccid4`)

หยุดระบบ ข้อมูลยังอยู่:

```bash
docker compose -f docker-compose.local.yml stop
```

เปิดระบบอีกครั้ง:

```bash
docker compose -f docker-compose.local.yml up -d
```

ดูว่าเครื่องถอดเสียงทำอะไรอยู่:

```bash
docker compose -f docker-compose.local.yml logs -f worker
```

เพิ่มบัญชีพนักงานสอบสวนอีกคน:

```bash
docker compose -f docker-compose.local.yml exec web python manage.py create_officer
```

สำรองฐานข้อมูลเป็นไฟล์:

```bash
docker compose -f docker-compose.local.yml exec -T db pg_dump -U ccid4 ccid4 > ccid4-backup.sql
```

## แก้ปัญหา

| อาการ | วิธีแก้ |
|---|---|
| "ใช้ไมค์ไม่ได้" | เปิดผ่าน `http://localhost:8000` เท่านั้น (ไม่ใช่ IP) กดรูปแม่กุญแจบนแถบที่อยู่ → อนุญาตไมโครโฟน และปิดโปรแกรมอื่นที่ใช้ไมค์อยู่ เช่น Zoom หรือ Teams |
| ถอดเสียงช้ามาก | ปิดโปรแกรมอื่น เสียบสายชาร์จ ใช้โมเดล turbo หรือตั้ง `ASR_BEAM_SIZE=1` ใน `.env` แล้วสั่ง `up -d` ใหม่ (เร็วขึ้นราว 2 เท่า แม่นลดลงเล็กน้อย) |
| หน้า "ประมวลผล" ขึ้นว่า "ยังไม่เปิดใช้โมเดลถอดเสียง" | รันตัวติดตั้งใหม่อีกครั้ง (โหลดโมเดลไม่สำเร็จ เช่น เน็ตหลุดระหว่างโหลด) |
| หน้าเว็บไม่ขึ้น | ตรวจว่า Docker Desktop เปิดอยู่ แล้วสั่ง `docker compose -f docker-compose.local.yml up -d` |
| Docker แจ้งว่าพอร์ต 8000 ถูกใช้ | ปิดโปรแกรมอื่นที่ใช้พอร์ต 8000 แล้วเปิดระบบใหม่ |

## ใช้ Typhoon Whisper (ภาษาไทยโดยเฉพาะ) บนเครื่องที่มี GPU

Typhoon Whisper เผยแพร่เป็นโมเดลแบบ transformers จึงต้องแปลงเป็น CTranslate2 ก่อนใช้ (แปลงครั้งเดียว ต้องใช้หน่วยความจำมาก)

1. ดูชื่อรุ่นที่ถูกต้องในหน้า Hugging Face ของ Typhoon (เช่น `<องค์กร>/<ชื่อรุ่น>`)
2. รันคำสั่งนี้ โดยแทนชื่อรุ่นที่ได้จากข้อ 1

   ```bash
   docker compose -f docker-compose.local.yml run --rm -e HF_HUB_OFFLINE=0 worker sh -c 'pip install --user "transformers[torch]" && python manage.py setup_asr --model <ชื่อรุ่น> --convert'
   ```
3. นำบรรทัด `ASR_MODEL=…` ที่คำสั่งพิมพ์ออกมาไปใส่ใน `.env` แล้วสั่ง `up -d`
4. ถ้าเครื่องมี GPU ให้ตั้ง `ASR_DEVICE=cuda` และ `ASR_COMPUTE_TYPE=float16` แล้วใช้ `docker compose --profile gpu` ตาม `docker-compose.yml`
