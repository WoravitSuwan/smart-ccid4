# CLAUDE.md — กติกาประจำโปรเจกต์ CCID4

ไฟล์นี้ Claude Code อ่านทุกครั้งที่เริ่มงาน ใช้เป็นกติกาถาวรของโปรเจกต์

## โปรเจกต์นี้คืออะไร
CCID4 คือระบบช่วยพนักงานสอบสวนของ บก.สอท.4 ทำสำนวนคดีครบวงจร
- รับแจ้งความ เก็บข้อมูลคู่กรณี ติดตามกำหนดเวลาตามกฎหมาย และออกเอกสารในสำนวนอัตโนมัติ
- มีโมดูลเพิ่มสำหรับงานไซเบอร์ เช่น หมายเรียกจากทะเบียนคดีของกอง บันทึกเสียงสอบปากคำ บัญชีม้า และการเชื่อมโยงข้ามคดี
- สเปกเต็มอยู่ที่ `docs/SPEC_CCID4.md` อ่านก่อนเริ่มงานทุกเฟส
- สเปกย่อยของโมดูลหมายเรียกอยู่ที่ `docs/SPEC_summons_system.md`
- สเปกย่อยของโมดูลบันทึกเสียงอยู่ที่ `docs/SPEC_interview_recorder.md`

## วิธีทำงาน
1. ทุกเฟส: อ่านสเปก → เสนอแผนเป็นข้อ ๆ (ไฟล์ที่จะสร้าง/แก้, โมเดล, หน้าจอ, เทสต์) → รอผมอนุมัติ → ค่อยลงมือ
2. ทำทีละเฟสตาม `docs/SPEC_CCID4.md` หัวข้อ "เฟสการพัฒนา" ห้ามข้ามเฟส
3. จบเฟสต้องมีทั้งหมดนี้
   - เทสต์ผ่าน (`pytest`)
   - อัปเดต `docs/PROGRESS.md` ว่าทำอะไรไปแล้ว ค้างอะไร และตัดสินใจอะไรไว้
   - สรุปวิธีทดสอบด้วยมือให้ผม 3–5 ขั้น
4. ถ้าสเปกไม่ชัดหรือขัดกันเอง ให้ถามก่อน ห้ามเดา
5. อย่าลบหรือเขียนทับงานเดิมโดยไม่บอก

## เทคโนโลยี (ห้ามเปลี่ยนโดยไม่ถาม)
- **ภาษาและฐานข้อมูล:** Python 3.12, Django 5, PostgreSQL 16 (+ pgvector, pg_trgm), Celery + Redis
- **หน้าเว็บ:** Django templates + HTMX + Alpine.js + Tailwind CSS
  - ไม่แยก SPA
  - กราฟใช้ Cytoscape.js
  - คลื่นเสียงใช้ wavesurfer.js
- **เอกสาร:** python-docx + docxcompose, แปลง PDF ด้วย LibreOffice headless
  - ฟอนต์ TH SarabunIT๙ อยู่ในโฟลเดอร์ `fonts/`
- **AI ทั้งหมดรันในเครื่องของหน่วยงาน:** LLM ผ่าน Ollama/vLLM, ถอดเสียง Typhoon Whisper, OCR แบบ open-weight
  - เรียก AI ผ่าน `ai/` adapter เท่านั้น ห้ามเรียกโมเดลตรงจาก view
- **เทสต์:** pytest + pytest-django, factory_boy
- **รันระบบ:** docker compose (web, worker, db, redis, ollama, libreoffice)

## ความปลอดภัย (ห้ามละเมิด)
- **ห้ามเรียกบริการภายนอก**
  - ไม่ใช้ API AI ภายนอก ไม่ใช้ CDN ไม่ใช้ Google Fonts
  - ไฟล์ JS/CSS/ฟอนต์ทั้งหมดต้อง self-host
  - ตั้ง `HF_HUB_OFFLINE=1` หลังโหลดโมเดลครั้งแรก
- **ห้ามใช้ข้อมูลจริง**
  - ห้าม commit ข้อมูลคดีหรือข้อมูลบุคคลจริง
  - ใช้ข้อมูลตัวอย่างใน `sample_data/` และ seed ปลอมจาก Faker (locale `th_TH`)
- **บันทึกการใช้งาน:** ทุกการดู ส่งออก แก้ไข และลบข้อมูลบุคคลต้องเข้า `AuditLog`
- **ปิดบังข้อมูลบุคคล:** เลขบัตรประชาชนและเลขบัญชีแสดงแบบปิดบังเป็นค่าเริ่มต้น กดดูเต็มต้องมีสิทธิ์และถูกบันทึก
- **AI ร่าง คนตรวจ:** เอกสารหรือคำให้การที่ AI ร่างต้องมีป้าย "ร่างโดย AI – รอตรวจ" จนกว่าพนักงานสอบสวนจะกดยืนยัน
- **Secret:** อยู่ใน `.env` เท่านั้น และ `.env` อยู่ใน `.gitignore`

## หน้าตาและแบรนด์
- **โทนสี:** ฟ้า–ดำ ใช้ design token ใน `docs/SPEC_CCID4.md` หัวข้อ "ระบบดีไซน์" เท่านั้น
  - ห้ามใส่ค่าสีตรง ๆ ใน template ให้ใช้ CSS variables / Tailwind theme
- **โลโก้:** ใช้โลโก้ CCID4 ที่ออกแบบเอง (SVG ใน `static/brand/`)
- **ห้ามคัดลอกระบบเดิม:** ห้ามคัดลอกหน้าตา ข้อความ โลโก้ ภาพ หรือโค้ดของระบบ MetaCops
  - `docs/reference/MetaCops_สรุปการใช้งาน.pdf` ใช้อ้างอิงว่าระบบต้องทำอะไรได้เท่านั้น
  - เลย์เอาต์ คำบนปุ่ม และข้อความช่วยเหลือ ให้ทำตามสเปก CCID4
- **UI:** ภาษาไทยทั้งหมด วันที่แสดงเป็น พ.ศ. ฐานข้อมูลเก็บเป็น ค.ศ./UTC
